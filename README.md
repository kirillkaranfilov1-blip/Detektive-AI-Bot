# 🕵️‍♂️ Detektive AI

Интерактивная детективная игра в Telegram на базе искусственного интеллекта.

Вы играете за детектива, расследующего запутанные преступления. Опрашивайте ИИ-подозреваемых в свободной форме, собирайте улики, читайте показания и выдвигайте официальные обвинения в суде.

---

## 🛠 Технологический стек

- **Node.js** (v20+) / **TypeScript**
- **[grammY](https://grammy.dev/)** — современный быстрый фреймворк для Telegram-ботов
- **[Prisma ORM](https://www.prisma.io/)** — типобезопасная работа с базой данных (SQLite по умолчанию)
- **[OpenAI SDK](https://github.com/openai/openai-node)** — диалоги с подозреваемыми и вердикт ИИ-судьи (совместимо с OpenAI, OpenRouter, Groq, DeepSeek, Ollama)
- **Zod & Dotenv** — валидация конфигурации

---

## 🚀 Быстрый старт

### 1. Настройка окружения
В корне проекта отредактируйте файл `.env`:

```env
# Токен бота от @BotFather в Telegram
TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН_БОТА"

# API-ключ OpenAI (или совместимого сервиса)
OPENAI_API_KEY="sk-..."

# Опционально: URL API (по умолчанию OpenAI, можно указать Groq/OpenRouter/Ollama)
OPENAI_BASE_URL="https://api.openai.com/v1"
OPENAI_MODEL="gpt-4o-mini"

DATABASE_URL="file:./dev.db"
```

> 💡 **Примечание:** Если `OPENAI_API_KEY` не указан, игра автоматически переходит в **симулированный режим (fallback)**, что позволяет тестировать логику и интерфейс без затрат на токены.

### 2. Запуск проекта в режиме разработки

```bash
npm run dev
```

### 3. Продакшн сборка

```bash
npm run build
npm start
```

## 🎮 Возможности игры

- 🏛 **Дело «Тайна поместья Блэквуд»**:
  - Убийство сэра Артура Блэквуда в запертом кабинете.
  - 3 уникальных подозреваемых с собственными мотивами и алиби:
    - 💍 **Леди Элеонора Блэквуд** — надменная вдова с тайной связью.
    - 👨‍⚕️ **Доктор Джулиан Вэнс** — нервный семейный врач с огромными карточными долгами.
    - 🤵 **Томас Рид** — преданный дворецкий, заметивший подозрительные детали.
  - 6 физических и документальных улик (от чашки с остатками цианида до вощеной хирургической нити).
- 🎙 **Свободный диалог с подозреваемыми**: задавайте любые вопросы прямо в чат Telegram. Персонажи отвечают в характере, могут лгать, путаться или оправдываться.
- 📝 **Следственный блокнот**: хранит все найденные улики и статус дела.
- ⚖️ **Официальное обвинение и вердикт**: формулируйте свою версию преступления. ИИ-коллегия оценит вашу доказательную базу и выдаст рейтинг раскрытия (0-100 баллов).
